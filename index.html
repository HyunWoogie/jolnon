    What this browser model can / cannot do

    가능: MATLAB v2.16의 controller/plant 순서, 주요 nominal parameter, friction static-hold, delay, torque saturation, squareness, common/diagnostic trajectory, nearest-path contour 개념을 브라우저에서 즉시 조작.
    근사: browser trajectory discretization, nearest-path search, precompensation law는 발표/학습용으로 단순화. 따라서 MATLAB report 숫자와 1:1 일치시키는 용도가 아님.
    AI: 현재 정적 HTML에는 실제 neural model이 없음. 추후 MATLAB에서 생성한 학습데이터로 Python surrogate를 학습한 뒤 ONNX/TensorFlow.js 또는 Python backend로 붙일 수 있음.
